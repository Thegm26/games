# Who Enters?

## [Play Who Enters? on itch.io](https://thegm26.itch.io/who-enters)

A portrait browser game about guarding a castle gate: inspect each visitor's dossier, decide who may enter, and live with the consequences.

Swipe right to **Admit** and left to **Deny**. Buttons and keyboard controls are also available. Across five days and 40 visitors, use the optional Rulebook to weigh the evidence and protect the gate.

## Development

Built with Unity 6000.6.0f1 and verified headlessly. Project context and verification history live in [docs/SESSION_HANDOFF.md](docs/SESSION_HANDOFF.md); integration details are in [docs/integration/GATEHOUSE_INTEGRATION.md](docs/integration/GATEHOUSE_INTEGRATION.md).
