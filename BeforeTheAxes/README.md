# Before the Axes

A 3D stealth game built in Unity 6000.6.0f1. Escape through the forest while woodcutters patrol the area.

[Play Before the Axes on itch.io](https://thegm26.itch.io/before-the-axes)

## Core loop

- Travel through the forest and avoid woodcutters.
- Use tree form as a disguise; a tree seen moving at running speed gives you away.
- Find and carry the root mushroom objective.

## Controls

- **Move:** WASD or arrow keys
- **Run:** Shift
- **Crouch:** C or Ctrl
- **Tree form:** Space

## Project

Open the project with Unity 6000.6.0f1. Project content is kept in `Assets`, `Packages`, and `ProjectSettings`.

Third-party asset credits are recorded in [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md).
