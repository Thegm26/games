## itch project checklist

- Change the display title from the currently entered `who-enters?` to `Who Enters?`; retain the correct slug `who-enters`.
- Set the project to HTML / browser embed / WebGL for mobile portrait play; it is not Downloadable.
- Delete `Notes.txt` or leave it unpublished.
- Paste `ITCH_PAGE_COPY.md`, apply its exact ten tags, and mark AI disclosure Yes.
- Add `cover.png` and one supplied wallpaper asset. These wallpapers are promotional concept artwork, not gameplay screenshots.
- Leave itch.io's **Screenshots** field blank.

The game is Strategy: five nights, eight visitors each, 40 total decisions; swipe right to Admit and left to Deny; protect five integrity seals while recurring stories branch toward four endings. Audio is procedural at runtime only, with no external audio.
